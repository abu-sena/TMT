# Panduan Install — HUAWEI MatePad 11

## Untuk Orang Tua / Guru

### 1. Dapatkan File APK

File APK berada di:
```
android/app/build/outputs/apk/debug/app-debug.apk
```

Salin file ini ke HUAWEI MatePad 11 dengan salah satu cara:
- **Kabel USB**: hubungkan tablet ke komputer, salin APK ke folder Downloads
- **Bluetooth / Nearby Share**: kirim dari HP lain ke tablet
- **Cloud storage**: upload ke Google Drive / HUAWEI Cloud, download di tablet
- **Email**: kirim APK sebagai attachment ke email yang dibuka di tablet

### 2. Izinkan Install dari Sumber Eksternal

Saat pertama kali install APK dari luar AppGallery:

1. Buka **Settings** (Pengaturan)
2. Pilih **Security & privacy** (Keamanan & privasi)
3. Pilih **More settings** (Pengaturan lainnya)
4. Aktifkan **Install apps from external sources** (Izinkan instal dari sumber eksternal)
5. Pilih browser/file manager yang akan digunakan untuk membuka APK, lalu izinkan

> Jika muncul peringatan "Unknown app", pilih **Allow** atau **Izinkan**.

### 3. Install APK

1. Buka aplikasi **Files** (File Manager) di tablet
2. Cari file `app-debug.apk` di folder Downloads (atau tempat APK disimpan)
3. Tap file APK
4. Tap **Install** (Pasang)
5. Tunggu beberapa detik
6. Tap **Open** (Buka) atau **Done** (Selesai)

### 4. Buka Game

1. Cari ikon **Adab Quest** di home screen tablet
2. Tap untuk membuka
3. Game akan terbuka dalam mode fullscreen

### 5. Bermain Tanpa Internet

Adab Quest bisa dimainkan **100% offline**:
- Tidak perlu WiFi
- Tidak perlu data seluler
- Tidak perlu login Google
- Semua progres tersimpan di tablet

### 6. Cek Progress Tersimpan

Untuk memastikan progress aman:
1. Mainkan beberapa misi
2. Tutup aplikasi sepenuhnya (swipe dari recent apps)
3. Buka ulang aplikasi
4. Progress, poin, level, dan badge tetap ada

### 7. Google Connect (Opsional)

Game TIDAK membutuhkan login Google. Tombol "Sinkron Google" di Pengaturan hanya optional.

Jika HUAWEI MatePad 11 tidak memiliki Google Mobile Services:
- Game tetap berfungsi normal
- Tombol Google Connect mungkin tidak aktif
- Ini TIDAK memengaruhi gameplay

### 8. Troubleshooting

| Masalah | Solusi |
|---------|--------|
| APK tidak bisa diinstall | Pastikan "Install from external sources" sudah diizinkan di Settings |
| Game tidak terbuka | Restart tablet, coba buka lagi |
| Layar terlalu besar/kosong | Game sudah didesain untuk tablet. Jika ada ruang kosong, itu normal — konten tetap di tengah |
| Game lambat | Tutup aplikasi lain yang berjalan. Game ini ~500KB, seharusnya ringan |
| Progress hilang | Jangan hapus data aplikasi dari Settings. Jika pakai Google sync, coba restore |
| Tombol back Android | Back button akan kembali ke layar sebelumnya — didukung penuh |
| Suara tidak ada | Game belum memiliki sound effects (akan datang di update berikutnya) |
